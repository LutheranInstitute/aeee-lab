What this is

A portable Agent Skills package — the open standard at agentskills.io. OpenAI's own docs: "OpenAI Skills follow the Agent Skills open standard, so you can download them from one product and install them in another."

The same folder runs in ChatGPT, Codex, Claude, Cursor, Gemini CLI, and Hermes. Plain text — nothing to compile, nothing to migrate, no vendor lock.

HostHow

Hermes Agenthermes skills install <url>
Any other hostDrop the folder in that host's skills directory. It is plain text.

The two rules that carry the weight

// 1  A QR is an ADDRESS, not permission. Discovery never grants execution.
